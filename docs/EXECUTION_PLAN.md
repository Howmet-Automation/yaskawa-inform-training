1. Inventory: all 21 baseline sections and interactions mapped; evidence and gaps recorded.
2. Content: each section mapped to a route/component, substantive explanations and practice retained; compare against original directly.
3. Interactions: five-question minimum, answer feedback, invalidation, completion gate, timeline, timeout scenarios, desk activities, print worksheet, progress and instructor checkpoint restored.
4. Teaching: prerequisite order, explanation/worked example/practice/feedback, realistic troubleshooting, teach-back and next-shift retrieval; novice pilot targets 60–75 minutes.
5. Engineering: reproducible dependency lock, typecheck/build, unit and browser tests, mobile/keyboard/print checks, no broken links or console errors.
6. Release: all critical technical and safety checks pass, reviewer evidence recorded, instructor and novice pilot sign-off. Public and internal dispositions separate.
7. Module 02 blocked until Module 01 release requirements satisfied.
